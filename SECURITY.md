# Security

An input method sees everything you type, so security reports matter here. Please don't report vulnerabilities in public issues. Report them privately through [GitHub's vulnerability reporting](https://github.com/PythonShe/sugu/security/advisories/new) instead.

Examples include typed text leaving the Mac or being stored where it shouldn't be, input reaching password fields, and ways around the update feed's signature or the installer.

Fixes ship in the latest release, the only supported version.
